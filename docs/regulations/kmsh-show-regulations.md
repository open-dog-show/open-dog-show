# KMSH show regulations — index

Source: Koninklijke Maatschappij Sint-Hubertus (K.K.U.S.H.), _Reglement van de
tentoonstellingen_, Sectie 4A (VdA 17/02/2023, KR 23/03/2023). Index for design
cross-reference only; consult the official publication for authoritative text.

- ART.33 / §7 main-ring competitions: BIS, best veteran, best junior, best
  puppy, best minor puppy, plus BIG — identical feeder set to FCI §7.
- ART.4 show types: CAC, Open, Clubmatch, Young/Veteran days (not yet modelled).
- Bijlage 1 §4 (CACIB show) / Bijlage 2 §2-3 (CAC show): BOB draws on the adult
  certificate (CACIB or CAC) + junior/veteran class wins, both sexes present;
  BOS is the opposite sex to BOB.
